# 교량 사례를 이용한 3D QD 실험안

2026-09-13 사용자가 '다리'는 교량(bridge)을 의미한다고 확인했다. 현재 상태는 실험 계획이며 교량 생성·FEA는 실행하지 않았다.

## 권고 대상

**짧고 폭이 있는 단일 재료 일체형 보행교**로 시작한다. 거친 dense 생성 단계에서도 부재와 개구부를 표현할 수 있는 비율을 택한다. 가늘고 긴 케이블, 케이블 장력, 여러 재료·접합부를 처음부터 포함하지 않는다.

## 하나의 개발용 문제

- 고정: span, 폭, 상판의 사용 영역, 양 끝 지지 패치, 하중 패치, 재료, 허용 설계 영역.
- 비움: 교량 아래 사전에 지정한 통과 공간과 상판 위 사용 공간. 거대한 고체 블록이 최저 compliance라는 이유로 통과하지 않게 한다.
- 변경 허용: 측면·하부의 아치, 리브, 분기, 횡방향 연결, 거시적인 개구부.
- 첫 하중: 상판의 수직 분포 하중. 횡방향으로 치우친 하중을 별도 holdout load case로 추가해 3D 구조의 거동을 확인한다.
- 지지: 현재 solver의 전방향 고정과 실제 pin/roller를 혼동하지 않는다. 초기 단순 검증을 양단 고정으로 하면 그대로 명시한다. pin/roller 비교가 필요하면 region별 DOF 구속을 먼저 구현하고 검증한다.

후보 스타일은 단순 아치 / 고딕풍 굵은 리브 / 유기적인 분기 / 굵은 공간 트러스다. span·상판·지지 조건이 다른 그림들을 스타일 차이로 섞지 않는다.

## QD와 평가

주 archive는 고정 설계 영역의 재료 체적비 × 사전 정의한 재료 배치 특징을 사용한다. 교량의 기준축과 특징 정규화는 개발 실험에서 고정하고, 최종 mesh의 compliance로 품질을 판단한다.

시각적 차이 외에도 다음을 확인한다.

1. 같은 질량 구간에서의 compliance와 하중 전달 연결성.
2. 교량 아래 통과 공간, 상판, 지지 패치의 유지.
3. 횡방향 연결과 비대칭 하중에 대한 응답.
4. 같은 카메라의 최종 3D 렌더와 단면. 2D 실루엣만으로 3D 다양성을 주장하지 않는다.
5. 필요시 질량을 맞춘 '2D 설계 extrude' 비교군을 같은 3D verifier로 평가한다. 이는 해당 구조에서 3D 제어가 필요한지 보는 진단이며, 기존에 3D 방법이 없다는 주장은 아니다.

LMTO류, multi-start SIMP/BESO와의 비교도 전체 연구 계획의 동일 예산·동일 verifier 원칙을 따른다. 구조 안정성·좌굴·동적 거동까지 검증하지 않은 선형 탄성 결과를 실제 교량 설계 승인으로 해석하지 않는다.

## 필요한 구현과 예산

새 교량 CAD/voxel/keep-out, 상판 load patch, 지지 patch, 카메라와 domain별 해석 설정이 필요하다. 길쭉한 형상 때문에 dense 해상도와 FEA 해상도에 따른 차이를 먼저 측정한다. bracket의 mesh size·가이드 가중치·compliance cutoff를 그대로 복사하지 않는다.

개발 preflight → 작은 고정-bank QD 비교 → 독립 교량 문제의 본 실험 순서로 진행한다. 두 교량 test 문제는 단순 scale 변형이 아니라 지지 배치 또는 허용 구조 영역이 다른 독립 문제로 정한다. 문제 내부에서는 모든 방법의 지지와 하중을 동일하게 유지한다.

## 논문 구성에 반영

기본 8개 test 문제를 **산업 부품 4개 + 의자 2개 + 교량 2개**로 제안한다. 예: bracket 2, caliper 2, chair 2, bridge 2. Motor mount와 link는 후속 전이 평가 후보로 둔다. 개발용 CAD는 본 test와 분리한다.

이 구성은 평가 수를 추가하지 않고 사례 배분을 변경한 안이다. 다만 의자·교량의 실제 실행시간은 아직 측정하지 않았으므로 기존 13분/회 예산 가정은 preflight 이후 다시 계산한다.
