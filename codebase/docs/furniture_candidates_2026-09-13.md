# 3D QD 연구용 가구 후보

이 순위는 현재 생성기의 거친 dense 단계, 단일 재료의 선형 탄성 평가, 최종 의미 보존을 보여줄 필요를 고려한 제안이다. 실제 생성 성공률이나 제조 적합성을 측정한 순위는 아니다.

| 우선순위 / 역할 | 가구 | 적합한 이유 | 고정 조건과 주의점 | 형태 방향 예시 |
|---|---|---|---|---|
| 구현 첫 단계 | 등받이 없는 스툴 | 좌판과 지지부가 명확하고, 단일 좌판 하중으로 시작 가능 | 좌판 사용 면적·높이, 바닥 접촉부, 앉는 공간을 고정 | 아치형 연결, 가지형 다리, 두꺼운 연속 곡면 |
| 논문 대표 사례 | 단일 재료 일체형 라운지체어 | 등받이·팔걸이·하부 구조에 시각적 의미를 표현할 수 있음 | 좌판·진입 공간·지지부를 보존; 등받이 하중은 별도 검증 | 아보카도, 펭귄, 튤립, 산호에서 영감을 받은 실제 3D 형상 |
| 두 번째 가구 계열 | 조형적 사이드테이블 | 상판 기능을 고정하면서 하부 재료 배치가 크게 달라질 수 있음 | 상판 두께·하중 패치·바닥 지지를 명시; 편심 하중 평가 | 분기형 기둥, 열린 아치 받침, 비대칭 곡면 |
| 후속 난도 확장 | 짧은 벤치 | 긴 span과 여러 하중 위치로 구조 성능 차이를 검증 가능 | 길고 얇은 부재는 dense 해상도에 불리; 다중 하중 비용 증가 | 유기적 아치, 굵은 트러스, 개방형 하부 프레임 |

권고 조합은 **스툴로 평가기 연결 → 라운지체어로 의미/스타일과 QD 본 실험 → 사이드테이블로 범용성 확인**이다. 첫 실험부터 얇은 와이어 의자, 쿠션·천·금속이 섞인 의자, 바퀴·회전 관절·접이식 기구를 포함하면 현재 해석 범위를 벗어나는 문제가 늘어난다.

스툴의 구조 최적화 적용은 실제 설계 연구에서도 확인된다. 여기서 권고한 isotropic 단일 재료 문제는 아래 연구의 방향성 생체복합재 설정을 그대로 재현하는 것이 아니다. [Harvard MaP+S의 stool topology optimization 사례](https://research.gsd.harvard.edu/maps/2025/07/15/biocomposites-computational-framework/)
